データソースと仕組み

CEX 価格 — Binance

Binance の公開 REST API (/api/v3/ticker/price) から リアルタイムの板取引価格を取得。APIキー不要・CORS 対応済み。

オンチェーン価格 — DeFiLlama

DeFiLlama Coins API がオンチェーンの DEX プール （Uniswap V3, Curve, Raydium 等）から価格を集計。 コントラクトアドレスを直接指定してクエリ。

乖離率の計算式

乖離率 = (DEX価格 − CEX価格) / CEX価格 × 100

正値: DEX > CEX → CEXで買いDEXで売る裁定機会
負値: CEX > DEX → DEXで買いCEXで売る裁定機会

通知チャネル

ブラウザ通知 (Notification API)・Discord Webhook・ Telegram Bot API に対応。Telegram は CORS 制限がなく 静的サイトから最も安定して利用できます。
